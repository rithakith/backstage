## Important Notes

- The frontend plugin depends on catalog annotations generated by the WSO2 APIM catalog backend module.
- The frontend plugin calls the WSO2 API Manager backend plugin for runtime operations such as revision checks, API key generation, gateway discovery, service catalog access, document downloads, and WSDL downloads.
- The Asgardeo catalog backend module is optional. It syncs identity data into the Backstage catalog and is not required for WSO2 API ingestion.
- The Asgardeo auth backend module is optional. It enables Asgardeo sign-in through Backstage auth and pairs naturally with the Asgardeo catalog backend module.
- Some existing README files contain encoding artifacts. This documentation avoids those artifacts and uses plain Markdown.
