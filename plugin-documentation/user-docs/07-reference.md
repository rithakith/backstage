# Reference

This page summarizes user-facing reference information.

## Main Pages and Cards

| Item | Purpose |
| --- | --- |
| WSO2 API Manager page | Main WSO2 overview page at `/wso2-api-manager`. |
| WSO2 About card | Shows WSO2 API metadata such as lifecycle, context, version, provider, owners, and endpoints. |
| WSO2 API Overview card | Shows API overview information and documents where available. |
| WSO2 API Definition card | Shows API definition, operations, policies, gateway URLs, and runtime actions. |
| WSO2 Documents card | Shows and downloads WSO2 API documents. |
| WSO2 MCP Tools card | Shows MCP tools for MCP server entities. |
| WSO2 API Product Resources card | Shows API product resources and operations. |

## Important Entity Annotations

Most users do not need to edit annotations manually. They are generated by the WSO2 catalog provider.

Useful annotations to recognize:

| Annotation | Meaning |
| --- | --- |
| `wso2.com/api-id` | WSO2 API, product, or MCP id. |
| `wso2.com/api-name` | WSO2 name. |
| `wso2.com/api-version` | WSO2 version. |
| `wso2.com/api-context` | API context. |
| `wso2.com/api-provider` | Provider. |
| `wso2.com/api-lifecycle-status` | Lifecycle state. |
| `wso2.com/api-type` | API type. |
| `wso2.com/api-documents` | Document metadata. |
| `wso2.com/api-endpoints` | Endpoint metadata. |
| `wso2.com/gateway-endpoints` | Gateway endpoint metadata. |
| `wso2.com/is-api-product` | Marks an API product entity. |
| `wso2.com/product-resources` | API product resources. |
| `wso2.com/is-mcp-server` | Marks an MCP server entity. |
| `wso2.com/mcp-tools` | MCP tools. |
| `wso2.com/is-service` | Marks a Service Catalog service entity. |
| `wso2.com/service-id` | WSO2 service id. |
| `wso2-gateway.com/api-id` | API id for a gateway-discovered entity. |
| `wso2-gateway.com/api-endpoints` | Gateway-discovered endpoint metadata. |

## Main Configuration Blocks

| Config block | Purpose |
| --- | --- |
| `wso2ApiManager` | WSO2 API Manager URL, API base paths, OAuth credentials, TLS behavior. |
| `catalog.providers.wso2Apim` | WSO2 catalog ingestion namespace and schedule. |
| `wso2PlatformGateway` | Optional self-hosted gateway display and discovery configuration. |
| `catalog.providers.asgardeo` | Optional Asgardeo user and group catalog sync. |
| `auth.providers.asgardeo` | Optional Asgardeo sign-in configuration. |

## Runtime Actions

| Action | Requires backend plugin | Notes |
| --- | --- | --- |
| Gateway listing | Yes | Uses APIM settings and configured gateways. |
| API key generation | Yes | Uses WSO2 DevPortal path and service-account behavior in inspected source. |
| Revision lookup | Yes | Uses WSO2 Publisher revisions endpoint. |
| Service listing | Yes | Uses WSO2 Service Catalog. |
| Service usage | Yes | Uses WSO2 Service Catalog. |
| Service definition download | Yes | Returns text content. |
| WSDL download | Yes | Streams WSDL content. |
| Document content download | Yes | Streams or returns WSO2 document content. |

## When to Use Developer Docs

Use developer docs when you need:

- Exact backend API route behavior.
- Source-level configuration details.
- Entity annotation mapping rules.
- Token fallback behavior.
- Testing guidance.
- Extension guidance.
- Known implementation gaps.
