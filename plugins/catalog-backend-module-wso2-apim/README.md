# @rk-apim-1/backstage-plugin-catalog-backend-module-wso2-apim

This is a catalog module for the **WSO2 API Manager** integration. It provides an `EntityProvider` that automatically discovers and ingests APIs, API Products, and MCP Servers from WSO2 into the Backstage Catalog.

> [!IMPORTANT]
> **This package is part of the WSO2 suite.**
> Please see the [Main Plugin Page](https://npmjs.com/package/@rk-apim-1/backstage-plugin-wso2-api-manager) for full installation and configuration instructions.
