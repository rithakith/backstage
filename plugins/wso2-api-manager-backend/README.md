# @local/backstage-plugin-wso2-api-manager-backend

This is the backend plugin for **WSO2 API Manager** in Backstage. It provides the proxy API and authentication logic required by the frontend plugin.

> [!IMPORTANT]
> **This package is part of the WSO2 suite.**
> Please see the [Main Plugin Page](https://npmjs.com/package/@local/backstage-plugin-wso2-api-manager) for full installation and configuration instructions.
